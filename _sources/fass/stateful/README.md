# 有状态

有状态资源包括缓存、数据库、对象存储、文件存储和消息类资源。函数计算本身强调无状态，但真实业务通常需要把状态交给受控云资源管理。

## 适用范围

- 函数需要读写数据库或缓存。
- 函数需要保存文件、图片、报表或中间结果。
- 工作流中的多个步骤需要共享状态。
- 调试和验收需要保留可检查的数据证据。

## 工作原则

- 函数内部不保存长期状态。
- 数据库、存储和网络资源要按项目和环境隔离。
- 敏感数据访问要走最小权限。
- 状态资源要有备份、清理和成本控制策略。

## 常见资源

| 资源 | 用途 |
|------|------|
| 数据库 | 结构化业务数据 |
| 缓存 | 临时状态和加速访问 |
| 对象存储 | 文件、图片、报告和数据包 |
| 文件存储 | 需要挂载目录的计算任务 |
| 消息队列 | 异步任务和削峰 |

## 交付标准

- 明确状态资源名称和用途。
- 明确访问权限和网络边界。
- 明确数据保留和清理策略。
- 明确调试方式和验收证据。

## 快速检查

- 是否存在把状态写进函数本地目录的风险
- 数据库和存储是否按环境隔离
- 凭据是否未写进仓库
- 数据是否有备份或可重建方案
