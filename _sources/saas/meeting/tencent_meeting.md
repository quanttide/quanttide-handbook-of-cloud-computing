# 腾讯会议

腾讯会议章节记录腾讯会议接入云计算项目时的基本要求，适用于会议创建、会议查询、事件回调、录制处理和会议数据同步。

## 适用范围

- 需要通过 API 创建或管理会议。
- 需要同步会议成员、日程、录制或纪要信息。
- 需要把会议事件接入云函数或工作流。
- 需要为业务系统提供会议数据服务。

## 接入要点

- 确认腾讯会议账号、企业主体和应用权限。
- 明确 API 调用身份和密钥保存方式。
- 确认回调地址、验签方式和重试策略。
- 明确会议数据的存储位置和保留周期。

## 运行要求

- 凭据不进入 Git。
- 回调接口要记录请求和处理结果。
- 会议数据要按业务场景分级保存。
- 失败任务要能重试，重复事件要能去重。

## 快速检查

- 应用权限是否满足最小可用范围
- 回调地址是否可访问
- 验签逻辑是否启用
- 会议数据是否有保存和清理规则
- 异常日志是否可追踪
