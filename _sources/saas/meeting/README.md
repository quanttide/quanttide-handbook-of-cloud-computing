# 会议

会议章节记录会议类 SaaS 能力在云计算项目中的接入规范，重点关注账号权限、会议数据、回调事件和自动化处理。

## 适用范围

- 需要创建、查询或管理线上会议。
- 需要把会议数据接入业务系统。
- 需要处理会议回调、纪要、录制或参会记录。
- 需要把会议类 SaaS 能力嵌入自动化工作流。

## 工作原则

- 账号和应用权限要最小化。
- 会议数据要按业务场景限定访问范围。
- 回调事件要能验签、去重和重放。
- 录制、纪要和参会记录要明确保存周期。

## 子页面

- 腾讯会议

## 快速检查

- 是否明确账号和应用权限
- 是否记录 API 调用来源
- 是否处理回调重试和去重
- 是否明确会议数据保留周期
