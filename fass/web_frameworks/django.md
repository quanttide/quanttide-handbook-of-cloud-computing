# Django

Django 章节记录在云计算项目中使用 Django 的基本约定。它适用于需要把管理后台、API 服务或轻量 Web 应用部署到云函数、容器或其他云端运行环境的场景。

## 适用范围

- 需要 Django 管理后台。
- 需要 Django REST Framework 或类似 API 服务。
- 需要把已有 Django 项目迁移到云端环境。
- 需要和云数据库、对象存储、消息任务协同。

## 工作原则

- `settings` 要能区分本地、测试和生产环境。
- 数据库、缓存、存储桶和密钥都要通过环境变量注入。
- 静态文件和媒体文件不应依赖函数本地持久化。
- 部署后要验证 URL、数据库连接、迁移和日志。

## 交付标准

- 有明确的启动入口。
- 有环境变量清单。
- 有依赖安装说明。
- 有数据库迁移步骤。
- 有部署后验收记录。

## 快速检查

- `SECRET_KEY` 是否未进入仓库
- `DEBUG` 是否在生产环境关闭
- 数据库连接是否按环境隔离
- 静态文件和媒体文件是否有云端存储方案
- 日志是否能在云平台查看
