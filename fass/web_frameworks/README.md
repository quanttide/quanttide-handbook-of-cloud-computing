# Web框架

Web 框架章节记录 Django 等框架在函数计算和云端环境中的使用方式，重点关注入口适配、依赖管理、环境变量和部署验证。

## 适用范围

- 需要把传统 Web 框架部署到云函数或 Serverless 环境。
- 需要把 API、后台管理、任务接口等服务放到云端运行。
- 需要复用已有 Web 项目而不是完全改写为函数式接口。

## 工作原则

- 先确认框架入口，再确认云函数适配方式。
- 先处理配置和依赖，再处理业务功能。
- 环境变量、数据库和存储要与部署环境一致。
- 部署后必须通过 URL、日志和数据库连接做验收。

## 快速检查

- Web 入口是否适配云函数运行方式
- 依赖是否能在构建环境安装
- 静态文件和媒体文件是否有明确处理方式
- 数据库连接是否按环境隔离
